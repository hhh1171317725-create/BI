# 投放工具助手

该扩展包含两个功能：

- 京东商品主图批量下载。
- Adpflux 批量创建页关键词配置自动填充。
- Adpflux 素材库自动选择账户。
- Adpflux 账户管理页自动填写充值账户并查询。

## Adpflux 使用方式

1. 在浏览器中登录 `https://www.huanghaha.fun` 和 Adpflux。
2. 打开 Adpflux 的“广告批量创编”页面并进入“网站转化量”表单。
3. 在网站“账户对应关系”中点击某条配置的“创建广告”，插件会打开 Adpflux 并自动填写对应表单。
4. 也可以点击 Adpflux 页面右下角“关键词填充”，手动选择配置后填写。
5. 点击网站列表中的关键词，可以修改该关键词的推广系列数量和日预算；默认分别为 `1` 和 `20 USD`。
6. 点击“上传素材”会打开素材库并自动选择首个账户；点击旁边的“充值”会打开账户管理页、填写首个账户并查询。
7. 数据连接和优化事件需手动选择；检查素材及 TikTok 账号后，再自行提交。

全部字段填写成功后，关键词填充面板会自动收起；填写失败时会保持展开并显示待处理项。

扩展不会自动点击最终提交按钮。
