# 投放工具助手

该扩展包含以下功能：

- 京东商品主图批量下载。
- Adpflux 批量创建页关键词配置自动填充。
- Adpflux 素材库自动选择账户。
- Adpflux 账户管理页自动填写充值账户并查询。
- 创量出价监测定时同步。

## Adpflux 使用方式

1. 在浏览器中登录 `https://www.huanghaha.fun` 和 Adpflux。
2. 打开 Adpflux 的“广告批量创编”页面并进入“网站转化量”表单。
3. 在网站“账户对应关系”中点击某条配置的“创建广告”，插件会打开 Adpflux 并自动填写对应表单。
4. 也可以点击 Adpflux 页面右下角“关键词填充”，手动选择配置后填写。
5. 点击网站列表中的关键词，可以修改该关键词的推广系列数量和日预算；默认分别为 `1` 和 `20 USD`。
6. 点击“上传素材”会打开素材库并自动选择首个账户；点击旁边的“充值”会打开账户管理页，将全部账户 ID 按空格分隔后填写并查询。
7. 数据连接和优化事件需手动选择；检查素材及 TikTok 账号后，再自行提交。

全部字段填写成功后，关键词填充面板会自动收起；填写失败时会保持展开并显示待处理项。

扩展不会自动点击最终提交按钮。
## 出价监测定时同步（1.9.2）

更新插件后刷新网站出价监测页，在同一 Chrome 用户资料中保持网站及已登录的创量页面打开。
核对 client-user、main-user-id，选择间隔并点击“启用并立即同步”。默认每 10 分钟采集北京时间当天数据。
可先点击“读取当前创量用户”填写 client-user，main-user-id 仍需核对同一账户的实际值。页面每 3 秒显示分页进度，页面响应超时或后台中断会明确提示。
1.9.2 新增 cookies 权限及 cli1.mobgi.com 域名权限，仅通过 Cookie API 读取 userId（支持 HttpOnly 及接口域名），不读取登录令牌。升级后须重新加载扩展并允许新增权限，再刷新网页。
不需要粘贴 Cookie；只上传计划指标，不上传登录凭据。失败会暂停并保留上次快照，排除故障后重新启用。
Chrome 关闭或电脑休眠时不能更新。每个 Chrome 用户资料仅绑定一个网站用户和创量用户。
详见仓库 deploy/bid-monitor.md。
