# 数据助手分析升级

数据助手通过 `pet-loader.js` 出现在全站17个主页面，沿用服务器已有 AI 配置，不更换模型或凭据。大航海、京东日报保留数据分析；其他已登录页面支持AI问答和页面帮助，仅传递页面路径，后端按固定页面名称提供上下文，不读取表单、备忘录、聊天或终端内容，也不查询报表底表。登录页显示本地登录引导，不调用需登录的AI接口。

## 使用

- 日期：支持今天、昨天、前天、本周、上周、本月、上月、最近7天、8月以及完整日期范围。以北京时间为准；最近N天包含今天，单次最多366天。
- 对象：按底表中的优化师、项目、任务、媒体、账户等名称或ID匹配。相同维度多个对象为OR，不同维度为AND。请使用报表中的完整名称。
- 追问：先问“张三最近7天利润多少”，再问“ROI呢”或“李四呢”。新对象替换同一维度，其他已选条件保留；每轮显示实际查询范围。用“全部”清除对象限制，用“当前报表”回到页面范围；“新对话”清除聊天和查询状态。
- 对比：“最近7天对比上期”比较此前相邻7天，属于等长周期对比，并非自然月同比。任意两个独立日期比较暂不支持，助手会提示。
- 排名：“按利润给优化师排名”“ROI最高的优化师”“账户消耗排名”。先对全部匹配数据聚合并排序，再限制发送给模型的组数。
- 诊断：“诊断亏损并给出下一步建议”。服务器提供匹配汇总、前期数据、亏损优化师及无转化记录等证据；AI给出解释和验证建议。
- 输入：Enter发送，Shift+Enter换行；中文输入法选字不会发送。等待期间可点击“停止”，或用“新对话”中止本轮并重置；失败后可重试原问题。重试会重新读取当前已应用范围。客户端等待上限60秒，配置读取/保存上限10秒；停止只终止当前浏览器等待，服务器可能仍完成已经开始的请求，迟到回答不会进入对话。
- 阅读：回答支持加粗、段落、列表、代码块和表格，并提供“复制回答”。范围和降级原因显示在同一回答卡片中；上翻阅读时不会自动跳到底部，可点击“查看新回复”。Esc关闭设置或对话，手机面板随可视视口调整，打开及回答完成不会强制弹出键盘。

## 数据口径与限制

所有查询保留页面账户限制；切换页面日期或账户后清除旧对话查询状态。汇总由服务器从底表重新计算，不采用浏览器传入的汇总数字。日期缺行不等于零业绩，今天可能尚未回补完整。大航海账户佣金、结算、转化和注册沿用日报的账户消耗占比分摊口径，并非独立账户实测指标。

日报账户范围取最近成功应用的筛选，不读取尚未提交的输入草稿；刷新失败后继续使用画面中保留的报表范围。日报聊天请求只传递已加载标记、报表类型、已应用日期/账户和未知优化师过滤条件，省去重复汇总及维度数据；后端查数逻辑不变。未加载报表时提示先查询，不读取底表。

出价监测沿用当前筛选结果，向助手提供注册成本、预估eCPM和预估赔付，收益指标仅覆盖可匹配价格的计划。任务关联依据日报/open_url，不通过出价反推；历史逐日取单价和gap后合并，有注册但无有效结算时单价回溯，gap为有效日结算合计÷注册合计。助手依据本轮提供的指标和来源说明，不执行投放操作。

ROI以倍数表示；零成本ROI不参与排名。明细最多40/120行，维度最多80组，全量匹配汇总先于截断计算；发送给模型的上下文过大时明确省略明细或维度，不截断JSON文本。

AI未配置或请求失败时，页面明确显示规则分析。规则分析支持确定性查数、排名和对比，不能代替模型解释任意问题。模型不自动改价、停投或发送消息。对话只在当前页面内存中保留最近8条，不跨刷新保存。

模型返回完整结束状态且非空正文时才标为AI回答。截断、空内容、拒绝和服务异常分别提示，丢弃未完整生成的文本后提供已有规则结果。非标准代理如果省略结束状态，也会降级，避免将无法确认完整性的内容显示为完整分析。

## 验证与部署

```bash
./mvnw package
node scripts/pet-ui-test.cjs
node scripts/pet-global-ui-test.cjs
node scripts/pet-context-ui-test.cjs
node scripts/pet-interaction-ui-test.cjs
```

Java测试覆盖日期边界、范围继承和重置、账户分摊、京东指标、明细截断、利润与ROI排序、缺失上期、模型请求数据及失败降级。浏览器测试使用模拟API，覆盖追问、页面范围变化、新对话、降级提示、安全文本渲染与手机布局；不调用真实模型或生产数据库。

本轮补充实际日报页面的未应用/失败筛选范围测试，以及客户端取消、超时、迟到响应隔离、失败重试、中文输入、复制、阅读位置和模拟键盘可视视口检查；模型完整性用本地HTTP响应模拟和纯解析测试验证。

本次包含Java后端变更，部署需要重新构建并重启 `dahanghai-analysis`，只更新静态文件不够。生产模型可用性与回答质量仍需在部署后用实际报表验收。
