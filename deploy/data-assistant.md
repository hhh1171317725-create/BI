# 数据助手分析升级

数据助手位于大航海、京东日报页面。沿用服务器已有 AI 配置，不更换模型或凭据。

## 使用

- 日期：支持今天、昨天、前天、本周、上周、本月、上月、最近7天、8月以及完整日期范围。以北京时间为准；最近N天包含今天，单次最多366天。
- 对象：按底表中的优化师、项目、任务、媒体、账户等名称或ID匹配。相同维度多个对象为OR，不同维度为AND。请使用报表中的完整名称。
- 追问：先问“张三最近7天利润多少”，再问“ROI呢”或“李四呢”。新对象替换同一维度，其他已选条件保留；每轮显示实际查询范围。用“全部”清除对象限制，用“当前报表”回到页面范围；“新对话”清除聊天和查询状态。
- 对比：“最近7天对比上期”比较此前相邻7天，属于等长周期对比，并非自然月同比。任意两个独立日期比较暂不支持，助手会提示。
- 排名：“按利润给优化师排名”“ROI最高的优化师”“账户消耗排名”。先对全部匹配数据聚合并排序，再限制发送给模型的组数。
- 诊断：“诊断亏损并给出下一步建议”。服务器提供匹配汇总、前期数据、亏损优化师及无转化记录等证据；AI给出解释和验证建议。

## 数据口径与限制

所有查询保留页面账户限制；切换页面日期或账户后清除旧对话查询状态。汇总由服务器从底表重新计算，不采用浏览器传入的汇总数字。日期缺行不等于零业绩，今天可能尚未回补完整。大航海账户佣金、结算、转化和注册沿用日报的账户消耗占比分摊口径，并非独立账户实测指标。

ROI以倍数表示；零成本ROI不参与排名。明细最多40/120行，维度最多80组，全量匹配汇总先于截断计算；发送给模型的上下文过大时明确省略明细或维度，不截断JSON文本。

AI未配置或请求失败时，页面明确显示规则分析。规则分析支持确定性查数、排名和对比，不能代替模型解释任意问题。模型不自动改价、停投或发送消息。对话只在当前页面内存中保留最近8条，不跨刷新保存。

## 验证与部署

```bash
./mvnw package
node scripts/pet-ui-test.cjs
```

Java测试覆盖日期边界、范围继承和重置、账户分摊、京东指标、明细截断、利润与ROI排序、缺失上期、模型请求数据及失败降级。浏览器测试使用模拟API，覆盖追问、页面范围变化、新对话、降级提示、安全文本渲染与手机布局；不调用真实模型或生产数据库。

本次包含Java后端变更，部署需要重新构建并重启 `dahanghai-analysis`，只更新静态文件不够。生产模型可用性与回答质量仍需在部署后用实际报表验收。
