# 日报查询反馈

大航海日报与京东广义新日报共用 `daily-report-state.js`，统一查询状态与恢复操作。

- 初次加载就显示筛选区域，普通成员也能看到加载和失败原因，并直接重新查询。
- 修改日期、账户或优化师排除条件后，显示“筛选已修改，待应用”。当前结果范围始终来自已完成的查询。
- 刷新过程中保留现有报表；失败后明确标注仍为上次结果，不将错误伪装成零数据。
- 成功但无匹配数据时显示空结果说明。该状态不代表接口故障。
- 分析请求超过 45 秒通过 AbortController 结束浏览器等待，恢复查询按钮，允许缩小范围重试。此行为不保证服务端数据库查询已经取消，也不会自动重试。
- 同一页面分析查询串行执行；京东账户输入框连续回车不会重复发起分析请求。
- 日期同步接口仍使用原有流程，不受分析请求的 45 秒超时限制。

本次不修改佣金、ROI、gap、任务识别或赔付计算，也不改变数据库查询算法。

验证：

```sh
node scripts/daily-report-state-ui-test.cjs
node scripts/daily-polish-ui-test.cjs
```

测试通过本地 Chrome 和模拟 API 验证成员首次失败、重新查询、旧结果保留、筛选待应用、重复回车、空结果、重置、超时恢复及移动端布局。线上数据库耗时需要部署后单独测量。
