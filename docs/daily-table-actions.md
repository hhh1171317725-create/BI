# 日报表内查找与导出

大航海日报、京东广义新日报的汇总表和下钻明细支持：

- 表内查找名称、ID 或日期，多个关键词以空格分隔，所有关键词都匹配才展示。支持全角字符与大小写归一化。
- 输入后短暂等待或按 Enter 应用；Esc 或“清除搜索”恢复。中文输入法选字期间不提前过滤。
- 各维度分别保留本页面内的搜索词。切换维度时不会把优化师的关键词误用于日期或账户。
- 表内搜索只筛选该表格，不会重新请求服务端；顶部汇总与趋势图仍反映查询的日期及账户范围，匹配行提示同时说明这一点。
- 导出 CSV 使用当前排序、当前已选列和所有匹配行，包括未翻到的页。若没有匹配行，禁用导出。
- 导出文件名包含报表、维度、明细类型及当前结果日期；ROI 等比例列以百分比输出。
- UTF-8 BOM、引号、逗号及换行按照 CSV 格式处理。公式形式文本与 16 位以上纯数字文本加前置单引号，便于电子表格保留文本而非执行公式或舍入 ID。

搜索索引按数据数组和字段缓存，数据刷新后使用新数组自动重建。下载前若输入框仍有待应用关键词，先立即应用，避免导出上一次搜索结果。

## 表格展示

参考 [Ant Design ProTable 的工具栏](https://procomponents.ant.design/components/table/)的密度、展开、展示列操作，使用共享的轻量脚本实现，无新增第三方依赖。

- 搜索、导出和展示选项统一使用紧凑工具栏样式。
- 紧凑行距同时作用于汇总和明细表，在本机浏览器保留，两个日报页面共用偏好；标准行距仍是首次访问默认值。
- 时间维度支持收起/显示趋势，切换维度和刷新保留偏好。无数据趋势缩小高度，减少空白。
- 桌面端支持展开当前汇总表，保留已选列、搜索、排序和分页。原生 Fullscreen API 使焦点范围跟随展开区域；退出按钮或 Esc 返回，浏览器不允许时显示可重试提示。
- 横向滚动时固定名称列；手机继续使用卡片布局，不固定列、不显示桌面展开按钮。
- 维度标签支持左右方向键、Home、End，并同步选中状态；只把当前选中维度放入 Tab 顺序。

展示设置只改变 DOM/CSS，不调用分析接口，也不改动报表计算。展开后的趋势图暂时收起，退出后恢复先前展示状态。

覆盖 35 行跨页导出、当前排序及已选列、多词搜索、无结果、输入法、维度切换、下钻导出、长 ID 和手机布局。10,000 行索引验证重复搜索无需重新读取名称字段。浏览器下载校验 CSV 内容；不包含各电子表格软件的导入界面测试。

无数据库变更，部署命令：`sh scripts/deploy-server.sh`。
