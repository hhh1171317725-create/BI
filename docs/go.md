# 围棋（本地双人）

入口：工具中心 → 游戏大厅 → 围棋。也可登录后打开 `/go.html`。

- 9、13、19 路可选，默认 9 路；黑先白后，白贴 7.5 目。
- 同一设备交替落子，支持提子、禁自杀、全局同形禁着（落子后不能重复历史棋盘）、悔棋、停一手和认输。
- 双方连续停一手进入结算，点击整块棋标记或取消死子；双方确认后结束。有争议时可继续对局。
- 数子法：盘上活子加单方围住的空点，白方加贴目，提子不重复计分。死活、双活等复杂情况不自动裁决，需双方确认，本功能为休闲玩法。
- 方向键选择交点，回车或空格操作。更换棋盘或重新开局会询问确认。
- 对局仅保存在当前页面内存，刷新或离开页面会重置；本版本不提供围棋人机或远程房间。五子棋原有功能保留。

验证：`node scripts/go-core.test.cjs`，以及配置 Playwright 后运行 `node scripts/go-ui-test.cjs`、`node scripts/games-ui-test.cjs`。

部署只需更新前端静态文件，不涉及数据库或 Java 服务重启。
