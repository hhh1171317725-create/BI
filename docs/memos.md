# 备忘录

入口：网站侧栏「备忘录」或工具中心「备忘录」，页面 `/memos.html`。

- 登录账号各自独立保存，管理员也只能读取自己的备忘录。
- 标题、正文、标签支持关键词查询；空格分隔的多个关键词需要全部命中。
- 标签用中文或英文逗号分隔，最多 10 个，每个最多 24 字符。可按标签筛选。
- 常用信息可置顶；其余按最近更新时间排序。列表每次最多 30 条，只读取正文摘要，点击后加载全文。
- 点击保存或 Ctrl / Cmd + S 保存到数据库。离开未保存内容会提示。多个窗口修改同一条记录发生版本冲突时，不覆盖服务器内容，保留编辑区输入，需先复制后重新打开核对。
- 删除移入回收站，可恢复；当前不自动清空回收站。不上传附件、不接入钉钉采集。

首次访问 API 会自动创建 `personal_memos` 表（MySQL 5.7 兼容，utf8mb4）。使用现有数据库和登录会话，无新增运行时依赖。所有读写查询限制 `user_id`，参数化 SQL，搜索中的 `%`、`_` 按字面匹配。正文以纯文本展示，不能执行 HTML 或脚本。账号本身的注销/删除数据策略沿用现有系统，此功能没有新增自动清理。

查询按账号索引限定范围；当前使用 LIKE 保持中文子串查询，无需部署搜索引擎。数据量很大时仍可能受正文扫描影响，不声称全文索引级性能。

部署：

```sh
cd /www/wwwroot/BI
sh scripts/deploy-server.sh
```

验证：`./mvnw test -Dtest=MemoServiceTest,MemoApiControllerTest`；`node scripts/memos-ui-test.cjs`；`node scripts/app-shell-ui-test.cjs`。浏览器用例使用模拟 API，Java 用例使用 JDBC mock；上线前后应在真实 MySQL 做新增、重开、搜索、删除恢复的冒烟检查。
