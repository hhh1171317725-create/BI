# 出价监测查询与交互优化

- 任务、优化师多选先在下拉框中编辑，确认后统一应用。取消、Escape 或点击外部放弃草稿；Ctrl/Cmd+Enter 确认。没有改变选择时不重算报表。
- 下拉框统一单列布局，搜索区和操作区保持可见，长列表独立滚动，小屏限制在视口内。
- 成员共享报表仅在任务价格、策略版本或快照变化时更新对应部分。价格未变化时保留数组引用，继续命中分析缓存。
- 后台共享快照更新不打断历史查询；历史报表的刷新按钮继续查询所选日期。
- 历史任务、价格和 gap 的异步响应绑定原查询的数据对象，避免旧请求覆盖新查询。
- 同一日期的 gap 刷新失败时保留上次成功结果并提示重试；跨日期查询不沿用旧日期的关联结果。

## 验证

- 11 项 Node 回归测试通过，覆盖历史加载、gap 自动同步、分析缓存和新查询状态逻辑。
- 浏览器测试通过：管理员报表、多选、历史刷新、共享成员访问及移动端布局。
- 多选测试确认批量编辑期间不触发报表重绘，确认时仅重绘一次。
- 模拟 30 次共享版本不变的轮询，未触发表格重算或策略卡片重绘；版本变化后正常更新。

本次改进主要减少浏览器重复计算和查询交互中断，没有修改服务端 SQL，也未在生产环境测量接口耗时。
