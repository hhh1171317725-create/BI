# 工作台布局与操作优化

参考 Ant Design 数据列表规范和 Google Material 数据表格规范，针对投放数据的高频筛选、横向比较和详情核对调整现有页面。

参考资料：
- https://ant.design/docs/spec/data-list/
- https://m1.material.io/components/data-tables.html

| 调整前 | 调整后 | 用途 |
| --- | --- | --- |
| 顶部读取提示、汇总标题和说明各占一行 | 读取状态靠近页面标题，指标独立卡片，详细说明可展开 | 让首屏留出更多空间显示数据 |
| 日期、任务关联与 gap 长说明常驻 | 集中到“数据状态与计算口径”，显示加载状态，出错时自动展开 | 降低阅读负担，保留排错入口 |
| 大量字段逐个勾选 | 自定义列增加“投放表现”“收益分析”“投放设置”快捷方案 | 先选常用组合，再微调并确认 |
| 多套卡片、按钮和边框尺寸 | 出价监测、大航海日报、京东广义新日报、工具中心统一更克制的间距与边框 | 保持跨页面的视觉一致性 |

保留现有财务计算、权限、归档、预警判断和默认全部计划行为。快捷列方案只更改展示列；取消弹窗不会应用草稿。移动端继续采用换行布局，表格保留横向滚动。
