结算与判断口径

计算口径
回传比例 = 转化数 ÷ 注册数
理论保本出价 = 客户结算单价 ÷ 回传比例
目标出价上限 = 理论保本出价 ×（1 − 目标毛利率）
注册成本 = 消耗 ÷ 注册数；估算利润 = 注册数 × 客户结算单价 − 消耗

假设每个媒体注册均按该单价结算，出价与这里的回传转化目标一致。若是深度出价、双出价或其他结算事件，不适用本判断。未计入返点、退款及其他费用。低于上限不代表必然跑量或盈利。

Excel 首行为字段名，支持创量字段 stat_cost / convert_cnt / active_register / cpa_bid，或“消耗 / 转化数 / 注册数 / 出价”；计划名称、计划 ID、账户名称、账户 ID 为可选列。应使用所选统计区间的计划汇总表，不混入总计行或重复计划。

包含当天的数据尚可能回补。早上点击、下午注册会改变比例与成本，勿据此频繁调整出价。
